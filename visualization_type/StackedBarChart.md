# Stacked Bar Chart

Also known as: stacked bar graph
A stacked bar chart is a special type of bar chart that displays categorical data with rectangular bars whose length or height corresponds to the value of each data point but in addition, each bar displays subgroup information.  There are two ways of displaying subgroup information in a stacked bar chart.  The first is using whole numbers or percentages that don’t add up to 100%, the second is to display values as a percentage of a whole as in a 100% stacked bar.  

The length of each bar communicates the total value of a main category which is a sum of its subgroup values, and the length of each subgroup represents their individual values. 

Stacked bar charts are best used to compare data between the categories and between subgroups.  However, it is difficult to interpret values of subgroups across the categories.  Stacked bar charts are best for depicting large changes of a subgroup or for gathering a quick, high-level view of the content. Stacked bar charts are not optimal for conveying detailed or subtle differences in the subgroup values. The values of the subgroups become harder to interpret with the increasing number of subgroups displayed.  The further the subgroup is away from the axis, the harder it is to interpret any differences.  If there is one subgroup being focused on, then place this subgroup at the bottom of the stack so that the differences can be more easily interpreted.

## Best Practices

### Essential

* Bars must always start at the zero origin.  The heights or lengths of the categories and subgroups are proportional to the values they represent. For this reason, bar charts that do not start at zero will mislead the viewer's assessment of the differences between the values.
* Include a legend or use direct labels.
* If the categories are ordinal, preserve that order within the display.
* Order subgroups consistently across categories.
* Maintain an even amount of space between bars unless the axis is date.  When using date for the axis then the spacing should be true to date (for example if there is a missing year leave a proportional gap).

## Additional Recommendations

### Recommended

* Use analytical reasoning to choose the order of the subgroup categories.  If your focus is on contrasting one subgroup with all the other subgroups, then place the group of interest closest to the origin to facilitate that interpretation.
* Use a sequential color scheme for the subgroups if they have an order.
* Use a qualitative color scheme if the subgroups do not have an order.
* Use a divergent color scheme if there is a natural midpoint of the data and it makes sense to show the graduated color scheme from one subgroup to another. 
* The size of the text used in the display should have importance with respect to interpreting the meaning of the chart.

### Not Recommended

* Don’t order subgroups by their alphabetical label as a default.
* Use caution when depicting more than five subgroups for each category unless it is useful to show the stacked bar and all the details. If there are lots of subcategories, consider using a different type of data visualization.

Notes on Example 2, and Example 3

* Of these two charts, the 100 percent bar chart is the preferred display of the information but both charts could use improvements.
