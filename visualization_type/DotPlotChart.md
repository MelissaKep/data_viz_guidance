# Dot Plot Chart

Also known as: Dot Plot Categorical Chart, Wilkenson Dot Plot, Cleveland Dot Plot, Strip Plots, Dot Chart.

A Dot Plot Chart is both a distributional and Comparison chart type.  One version is the Wilkenson dot plot.  This version of the dot plot is similar to a histogram, but the dot plot allows for each individual observation to be plotted as a dot.  Another version of the dot plot is the Cleveland dot plot which is similar to a bar chart or lollipop chart.  In this version, one dot is used to communicate the total for the category.  Both of these versions are considered dot plots.  Please also review the guidance for Histogram and/or Bar chart or Lollipop chart.    

Strip plots are similar to the Wilkenson Dot Plot but the values are plotted along one unique axis and dots with the same value can overlap.  This plot often utilizes jittering to spread out the overlapping dots on the graph.

The simplicity of the dot plot allows for easy communication of spread and modes of the data but this chart type is not recommended for large data sets.  

Drawbacks of the dot plot are:
* the dot size used to mark the data points on the chart can sometimes interfere with interpretation.  
* The size of the data set often limits the effectiveness of this chart type.  If there are too many dots, its harder to interpret the main point of the chart.

## Guidance

In addition to the guidance provided in this section, relevant guidance can also be found in the Agency Logo, Axes, Colors, Grids,  Legends, Source, Titles, Typography sections.

## Best Practices

### Essential

* Facilitate the most important analytic comparison by placing the relevant categories next to each other.  
* If any categories have been removed from the chart which would normally be displayed, then a statement of omission or exclusion is needed.
* Use labels which read from left to right.  If the category labels are too long along the x-axis, then switch the axis to improve label readability. 

### Avoid
* Never omit the space between categories.

## Additional Recommendations

### Recommended

* Make sure the dots are easily counted by either providing a scale, gridlines or symmetry to allow for the user to determine the count differences across the different categories.
* Visual components of the dot plot chart should be utilized with purpose to promote: 
  * readability, 
  * ease of interpretation,  
  * transparency, 
  * reduction of redundancy.   
The visual components that should be balanced in usage include axis labels, data labels, tick marks, color, legend, boldness, spacing … etc. 
* Category labels should clearly define the categories being represented. 
* Sort the categories in an analytic sense which helps understanding the main purpose of the chart.  If there is no natural analytic ordering (ex: ordinal variable), then sort the categories by size in descending order. Use consistent scales when creating small multiple charts. 
* Only use additional color to highlight the key purpose of the chart.
