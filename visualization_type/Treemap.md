# Treemap

A treemap is a visualization that displays hierarchical data as different groups of nested rectangles.

A treemap shares qualities with both network and area diagrams. It gets its name from a tree diagram which is also used to display hierarchical data. The key feature of a treemap is that the size of each rectangle represents the value of each category of data, making it possible to convey more information about each category of data in a smaller space.

Treemaps can be used to represent data that has a tree-like hierarchical relationship, such as categories of occupations, industries, or budgets. Occupations and industries are classified by a hierarchical structure, with broad groups and subgroups. Budgets are spent by organizations in a hierarchical structure.

Color can be used to show additional dimensions and should not represent the same information as the size of the rectangle. Adding interactivity allows for users to drill into each box to see its components.

In addition to the guidance provided in this section, relevant guidance can also be found in the Agency Logo, Colors, Grids, Legends, Source, Titles, Typography sections.

## Best Practices

### Essential 

* Ensure that any text displayed in each rectangle has a sufficient contrast ratio.

## Additional Recommendations

### Recommended

* Keep a straight edge on each side of the diagram.

### Not Recommended

* Don’t include patterns or images in each rectangle.
* Treemaps are not recommended for data types that have a natural order such as age ranges, educational outcomes, chronological data, and regional areas. Presenting these types of variables in a treemap makes interpreting the content much more cognitively taxing than if the data appeared in their natural order.
