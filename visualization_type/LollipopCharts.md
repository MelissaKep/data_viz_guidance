# Lollipop Charts


Also known as: Lollipop Graph, Dot Plot

A Lollipop Chart is a c chart type with a categorical axis and a length or height which corresponds to the value of each data point. 

Lollipop charts are preferred over bar charts when many of the categories have large values or when comparing more than ten categories.  The lollipop chart allows an easier assessment of differences in many values being compared.  One drawback of the Lollipop chart is the dot size used to mark the point on the chart which can interfere with interpretation.

## Best Practices 

### Essential 

* Lollipop charts must always start at zero.  The heights or lengths of the lollipops are proportional to the values they represent. For this reason, lollipop charts that do not start at zero will mislead the viewer's assessment of the differences between the values.
* The author must facilitate the most important analytic comparison by placing the relevant comparison categories next to each other in groupings.  
* If any categories have been removed from the chart which would normally be displayed, then a statement of omission or exclusion is needed.
* Never omit the space between lollipops.
* Authors must use labels which read from left to right.  If the category labels are too long along the x-axis, then make the lollipops horizontal along the y-axis to improve label readability.

## Additional Recommendations 

### Recommended  

* Visual components of the Lollipop chart should be utilized with purpose to promote: 
   * readability, 
   * ease of interpretation,  
   * transparency, 
   * reduction of redundancy.   
The visual components that should be balanced in usage include: axis labels, data labels, tick marks, color, legend, boldness, spacing … etc. 
* Category labels should clearly define the categories being represented. 
* Author shall sort the categories in an analytic sense which helps understanding the main purpose of the chart.  If there is no natural analytic ordering (ex: ordinal variable), then sort the categories by size in descending order. Use consistent scales when creating small multiple charts. 
* Only use additional color to highlight the key purpose of the chart.
