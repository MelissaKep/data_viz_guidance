# 508 Compliance

This section highlights the requirements for 508 compliance for data visualizations. All visualizations shared publicly on the web must follow these requirements.  For more information, see the latest version of the Web Content Accessibility Guidelines (WCAG) 2.1 AA

## Alt Text 

Alt text should always be used for data visualizations.  The alt text provides information for the visually impaired.  The text provided needs to be enough information to understand the main message of the chart or graph.  If this is not possible then data tables may be required.

## Data Tables

Data tables may be provided in addition to the alt text for any visualization in order to convey the full meaning of the data visualization to users with visual impairments.  Visually complex charts or graphs require data tables to break down the visual representation of the information provided in order to meet 508 WCAG compliance guidelines. For help meeting this requirement reach out to the Section 508 Program Office at census.508.accessibility@census.gov or reach out to Tamika Lewis of the Section 508 Program office. 

## Images and Images of text

Images or Images of text should be able to be resized up to 200 percent without loss of content or functionality. For help meeting this requirement reach out to the Section 508 Program Office at census.508.accessibility@census.gov or reach out to Tamika Lewis of the Section 508 Program office. 

## Color Accessibility

There are many considerations for the use of color within data visualizations.  The WCAG (Web Content Accessibility Guidelines) ensure that content is accessible by everyone. To meet these standards, text and interactive elements should have a color contrast ratio of [at least 4.5:1](http://www.w3.org/TR/UNDERSTANDING-WCAG20/visual-audio-contrast-contrast.html). This ensures that viewers who cannot see the full color spectrum are able to read the text or image. See our page on Color as well as WCAG Section 1.4.3 for more information.
